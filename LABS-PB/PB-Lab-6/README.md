# **Lab 6: Data Types, Operations and Expressions in C / Типи даних, операції та вирази мови C**

[English](#bookmark=id.llc3kvzgxzrn) | [Українська](#bookmark=id.8vgjnwxtxjsx)

## ---

**English**

C program that evaluates mathematical expressions using \<math.h\>, performs bitwise and ternary operations, and determines if a point (x, y) falls into the second quadrant of a circle. Includes UTF-8 console support for Windows.

### **Key concepts**

> * Data types, operator precedence, and implicit type casting  
> * Standard math library functions (pow(), log(), sqrt())  
> * Bitwise operations (\~, &, |, ^) and ternary conditional operator (? :)  
> * Geometric condition checks using logical operators (&&, \<=, \>=)  
> * UTF-8 console encoding setup via Windows API (SetConsoleCP(65001))

### **How to run**

`gcc main.c -o lab6 -lm`  
`./lab6`

## ---

**Українська**

Програма мовою C для обчислення складеного математичного виразу з бібліотеки \<math.h\>, виконання побітових і тернарних операцій, а також визначення потрапляння точки (x, y) у другий квадрант круга. Підтримує виведення кирилиці в консолі Windows (UTF-8).

### **Ключові концепції**

> * Типи даних, пріоритети операцій та неявне зведення типів  
> * Стандартні математичні функції бібліотеки \<math.h\> (pow(), log(), sqrt())  
> * Побітові операції (\~, &, |, ^) та тернарний умовний оператор (? :)  
> * Перевірка геометричних умов за допомогою логічних операторів (&&, \<=, \>=)  
> * Налаштування кодування UTF-8 у консолі Windows (SetConsoleCP(65001))

### **Як запустити**

`gcc main.c -o lab6 -lm`  
`./lab6`
