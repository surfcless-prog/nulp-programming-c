# Лабораторна робота №6 (Варіант 13)
**Курс:** Основи програмування (НУ «Львівська політехніка»)

## 📌 Опис
Консольна програма мовою C для обчислення математичних виразів, виконання побітових операцій та геометричної перевірки умов.

## 🛠 Структура
1. **Завдання 1:** Обчислення математичного виразу $x^{0{,}5k} + \ln\left(x + \frac{k - 3{,}25}{\frac{4}{7}x - \sqrt{x}}\right)$.
2. **Завдання 2:** Обчислення виразів з тернарним оператором `?:` та побітовими операціями (`~`, `&`, `^`, `|`).
3. **Завдання 3:** Перевірка належності точки $(x, y)$ II квадранту круга радіуса $R$.

## 🚀 Запуск
```bash
gcc main.c -o lab6 -lm
./lab6
```

# Laboratory Work #6 (Variant 13)
**Course:** Fundamentals of Programming (Lviv Polytechnic National University)

## 📌 Overview
A C console application demonstrating math expression evaluation, bitwise/ternary operations, and geometric region checks.

## 🛠 Features
1. **Task 1:** Evaluation of mathematical expression $x^{0.5k} + \ln\left(x + \frac{k - 3.25}{\frac{4}{7}x - \sqrt{x}}\right)$.
2. **Task 2:** Evaluation of expressions using ternary operator `?:` and bitwise operators (`~`, `&`, `^`, `|`).
3. **Task 3:** Checking whether a point $(x, y)$ belongs to the 2nd quadrant of a circle with radius $R$.

## 🚀 How to Run
```bash
gcc main.c -o lab6 -lm
./lab6
```
