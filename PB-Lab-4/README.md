# Lab 4: C Basics

Лабораторна робота №4 з предмета "Основи програмування" (НУ "ЛП")

## English

Basic C scripts written during Lab 4. Demonstrates console I/O, UTF-8 output setup for Windows, random number generation (`srand`/`rand`), and simple `for`/`if` logic.

### How to run

Compiled with GCC or inside Visual Studio:

```
gcc task2.c -o guess_game
./guess_game

```

## Українська

Базові скрипти мовою C в межах 4-ї лабораторної. Демонстрація робот з консольним введенням/виведенням, кирилицею у Windows (`chcp 65001`), генерацією випадкових чисел та циклами.

### Як запустити

Компіляція через GCC або у Visual Studio:

```
gcc task2.c -o guess_game
./guess_game

```
